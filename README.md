# وكيل عملاء فاتورتي 🧾

وكيل يشتغل كل يوم كمهمة مجدولة في Claude ويجيب عملاء لـ«فاتورتي» (فريلانسرز، أسر منتجة، أعمال صغيرة).

## وش يسوي كل يوم
1. **يرد على الاستفسارات** اللي تحطها في `data/inquiries/` ← الردود في `replies/`
2. **يتابع** العملاء اللي تواصلت معهم (متابعتين كحد أقصى)
3. **يبحث** عن ~15 عميل جديد من مصادر عامة ويقيّمهم من 10
4. **يكتب رسائل مخصصة** جاهزة للنسخ في `outreach/<التاريخ>.md`
5. **يكتب تقرير** في `reports/<التاريخ>.md` ويحدّث `data/leads.csv`

## روتينك اليومي (10 دقائق)
1. افتح `outreach/<تاريخ اليوم>.md`
2. راجع الرسائل، انسخها وأرسلها، واكتب `✅` تحت كل رسالة أرسلتها
3. أي رد يوصلك ← الصقه في `data/inquiries/` (أو في محادثة Claude لرد فوري)

## قبل أول تشغيل ⚠️
عدّل `agent/product.md` و`agent/faq.md` — كل سطر عليه ⚠️ افتراض لازم تصححه (الأسعار، المزايا، التوافق مع ZATCA، روابط التواصل). الوكيل ما يذكر أي معلومة مو مكتوبة هناك.

## الملفات
| الملف | الغرض |
|---|---|
| `agent/PROMPT.md` | تعليمات الوكيل خطوة بخطوة |
| `agent/product.md` | معلومات المنتج (أنت تعبيها) |
| `agent/rules.md` | قواعد الخصوصية والإرسال |
| `agent/templates.md` | قوالب الرسائل |
| `agent/faq.md` | أجوبة الاستفسارات |
| `data/leads.csv` | قاعدة العملاء (تفتح بالإكسل) |

## حالات العميل
`new` → `contacted` → `replied` → `interested` → `signed_up`
أو `cold` (ما رد بعد متابعتين) / `opted_out` (طلب عدم التواصل — ما نرجع له أبداً)
