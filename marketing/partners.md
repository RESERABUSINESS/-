# برنامج الشراكات

الهدف: جهة وحدة توصّل «فاتورتي» لعشرات المستقلين أو الأسر المنتجة مرة وحدة.

## الفئات المستهدفة
| الفئة | ليش | أين تلقاهم |
|---|---|---|
| وكالات محتوى/تصميم/فعاليات/تسويق | تستلم فواتير من مستقلين كل شهر | دليل عين الرياض (134، 77، 57، 194، 76) + مواقعهم |
| مساحات العمل المشترك | أعضاؤها فريلانسرز | بحث «مساحة عمل مشترك الرياض/جدة/الخبر» |
| حاضنات ومسرّعات أعمال | رواد أعمال ومشاريع صغيرة | بحث + منشآت (جهات شريكة) |
| جمعيات وبرامج الأسر المنتجة | مئات الأسر | بحث «جمعية الأسر المنتجة» + بازارات ومعارض |
| مراكز تدريب العمل الحر / وثيقة العمل الحر | متدربين يبدؤون العمل الحر | بحث + أدلة التدريب |
| أندية الطلاب / مراكز التوظيف بالجامعات | طلاب يشتغلون فريلانس | مواقع الجامعات |

## العرض للشريك
- أداة مجانية لأعضائهم، بدون تسجيل.
- نقدر نسوي لهم ورشة/جلسة قصيرة أونلاين «كيف تطلع فاتورة احترافية كمستقل» (يحتاج تأكيد صاحب المنتج قبل الوعد بتاريخ).
